# Personal website (Kjell Boyens)

One-page Streamlit site that introduces me and links ClimaLens and GreenProof.
It uses the same theme as the ClimaLens app (`.streamlit/config.toml` in the repo root).

Deploy on share.streamlit.io: repository `BoyensKjell/ClimaLens`, branch `main`,
main file path `website/app.py`, custom URL e.g. `kjell-boyens`.

Texts and links are in the PROFILE block at the top of `app.py`.
